# Модель экономики

Дашборд на Streamlit: состояние экономики и рынка США на одном экране и учебные экраны по темам.
Данные — FRED (без API-ключа), Yahoo Finance и таблица Роберта Шиллера.

| Экран | Что показывает |
|---|---|
| Панель | 18 приборов в 6 группах, фаза цикла, главные сигналы, текущий режим и что в нём выигрывало |
| Режим экономики | рост × инфляция, голосование рядов, история режимов, доходность активов по режимам |
| Ставки и облигации | кривая доходности, наклон, реальные ставки, кредитные спреды, песочница облигации |
| Ликвидность и долг | баланс ФРС, чистая ликвидность, M2, доллар, долговой цикл |
| Оценка рынка | CAPE и доходность следующих 10 лет, премия акций над облигациями, индикатор Баффета, модель Гордона |
| Акции и сектора | сила секторов и факторов к рынку, ротация, широта рынка, P/E по секторам, сектора в текущем режиме |
| Отдельная акция | чек-листы Грэма, Баффета и Линча, категория по Линчу, макро-контекст, бета и реакция на ставки |
| Все ряды / Данные | любой ряд из каталога; состояние кэша и обновление |

### Новая версия (по умолчанию)

Открывается по умолчанию; старую можно выбрать переключателем «Версия дашборда» в боковой панели. Новая версия
строит модель экономики как **цепочку из семи слоёв** (структура и долг → политика ФРС → рыночные ставки →
финансовые условия → рост → инфляция → рынки) по отчёту `reports/SOTA модели экономики.md`: «Карта» (ответ каждого
слоя по текущим данным и лаги между слоями), экран на каждый слой и «Справка» (как читать экраны, глоссарий, что
нового). Каркас учебной подачи — `core/learn.py`: главный вывод, метки надёжности
сигнала, «Как это работает», примеры на реальных данных по переключателю (обычная работа механизма и аномалии).

## Запуск

```bash
uv sync
uv run python update_data.py      # первая загрузка всех рядов (~1 мин), дальше — по необходимости
uv run streamlit run app.py
```

Тесты интерфейса: `uv run python tests/test_app.py`. Деплой на VPS (systemd + nginx): `deploy/DEPLOY.md`.

## Устройство

- `core/series.py` — каталог рядов; `core/data.py` — загрузка и дисковый кэш (`data_cache/`, в git не попадает).
- `core/indicators.py` — приборы панели и правила статусов; `core/phase.py` — фаза цикла.
- `core/regime.py`, `core/valuation.py`, `core/bonds.py` — расчёты экранов.
- `views/` — страницы (не `pages/`: это имя конфликтует с `st.navigation`).

Это учебный инструмент, а не инвестиционная рекомендация: макро-картина — контекст для решений, а не сигнал на сделку.
